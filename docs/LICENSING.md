## Felucca

Felucca is a **git submodule** at `felucca/`, pinned to tag `v1.0.2`
(`db70550344f36cb10657d1652f567b5932ac4b2b`), and is **unmodified**: Fluyt has no patch, no
cherry-pick and no local change against it, and the units compile Felucca's files exactly as
upstream ships them. Felucca is **GPL-3.0-only**, copyright (C) 2026 Leo Kuroshita
(@kurogedelic), Hügelton Instruments; its own `LICENSE` and `LICENSING.md` are inside the
submodule, and its licence texts are in `felucca/LICENSES/`.

Everything in Felucca that this repository compiles into a unit is GPL-3.0-only, with these two
carried-through exceptions, both of which are part of Felucca upstream and are recorded in
`felucca/LICENSING.md`:

| File | Licence | Where it is used |
| --- | --- | --- |
| `firmware/src/fm6_core.c` - a port of **msfa** by Google Inc. and Pascal Gauthier, from Dexed (<https://github.com/asb2m10/dexed>), to integer C | Apache-2.0 | pulled in by `eng_fm6.c:28`, so it is in **FLUYT FM6** |
| `firmware/src/eng_phase.c` - the PHASE waveforms, a C port of the oscillator of CrispyZebra (<https://github.com/hugelton/CrispyZebra>) | GPL-3.0 | **FLUYT PHASE** |

`firmware/src/drum_voice.c` (pulled in by `eng_drum.c:32`) is Hügelton Instruments' own work,
GPL-3.0-only. `firmware/src/felucca_fm6.h`, which the FM6 unit also needs, is generated by
Felucca's `tools/gen_fm6_patches.py` from Felucca's own factory patches, so it is Felucca's.

Nothing from Felucca's **sample** material, its fonts or its images is part of a unit: a drumlogue
unit is DSP code and nothing else. The three engines that need samples (SAMPLE, GRAIN, SLICE) and
PHYS are not built here, so `phys_dsp.c`, `phys_symp.c` (both MIT, DaisySP and Rings) and the CC0
and OFL assets stay untouched in the submodule.

**What this means for a Fluyt unit's binary.** A `.drmlgunit` built here contains Felucca's GPL-3.0
code (and, for FLUYT FM6, msfa's Apache-2.0 code), so the unit as a whole is **GPL-3.0-only**, and
distributing one means offering the corresponding source: this repository plus the Felucca
submodule at the pin above is exactly that source. There is no other material in a unit - no
vendor code, no sample data, no fonts.

## Generated tables

`shim/gen/` holds `felucca_tables.h` (and, for FM6, `felucca_fm6.h`), produced at build time by
**Felucca's own generators** run against the submodule, at the drumlogue's 48 kHz instead of
Felucca's 44.1 kHz. The generators are Felucca's (`felucca/tools/gen_tables.py`,
`gen_fm6_patches.py`, GPL-3.0-only), the output is derived from Felucca's source and tables, and it
is GPL-3.0-only for the same reason. It is not checked in - `build.sh` regenerates it - so a
release made from this repository should build it from the pinned submodule before offering the
sources, which `./build.sh` does.

## The logue SDK

The units are compiled against the **logue SDK** (<https://github.com/logue-sdk/logue-sdk>), which
is **BSD 3-Clause**, Copyright (c) 2018 KORG INC. Its headers are read from your SDK checkout at
build time and are not part of this repository - but one SDK file *is* copied in, the same way every
drumlogue unit copies it: each unit folder's `Makefile` is the SDK's
`platform/drumlogue/dummy-synth/Makefile`, verbatim and unmodified, and stays **BSD 3-Clause, KORG
INC.** The unit's own build configuration is `config.mk`, which is Fluyt's (generated by
`tools/gen_rows.c`) and is GPL-3.0-only like the rest.

A unit is a shared object the device loads; nothing of the SDK's is linked into it beyond the ABI
structures its headers declare and the small `_unit_base.c` the SDK compiles alongside it.

`felucca/LICENSE` is the GPL-3.0 text and is the same one this repository carries.
